# 刘天勤 · 22 岁生日快乐 🎂🌿

一个零构建的纯前端生日纪念网站：绿色系、双主题、火漆信封开场、手写信、吹蜡烛许愿、拍立得画廊、默契问答、祝福弹幕与烟花。

打开 `index.html` 即可运行，不需要 npm、不需要打包、不需要任何服务器端程序。

---

## 一、目录结构

```
happybirthday/
├─ index.html            页面结构（语义化标签 + 各弹窗容器）
├─ style.css             绿色双主题变量、3D 信封、毛玻璃、动画与响应式
├─ script.js             全部逻辑；所有可改内容集中在文件顶部的 CONFIG
├─ assets/
│  ├─ music/             自选歌曲（可选，缺失时自动降级为氛围音）
│  │  ├─ 22.mp3
│  │  ├─ forest-ambient.mp3
│  │  ├─ afternoon.mp3
│  │  └─ custom.mp3
│  └─ images/            真实照片（可选，缺失时自动使用内置绿色插画）
│     ├─ photo1.jpg … photo6.jpg
└─ README.md
```

## 二、本地预览

三种方式任选，推荐第 1 种（麦克风吹蜡烛、本地音频都需要它）：

### 1. 起一个本地静态服务器（推荐）

在本目录下执行任意一条：

```powershell
# Python 3（Windows 自带或已安装）
python -m http.server 8080

# Node.js 环境
npx serve .
```

然后浏览器打开 <http://localhost:8080>。

> 用 `http://localhost` 打开时，浏览器会把页面视为“安全来源”，
> 麦克风吹蜡烛、自动播放音乐都可以正常使用。

### 2. 直接双击 index.html

`file://` 协议也能完整浏览，只是：

- 麦克风权限通常拿不到 → 点击「用麦克风吹气」会提示，并自动改用「吹灭蜡烛」按钮；
- 部分浏览器会拦截自动播放 → 点一下右下角音乐胶囊的播放键即可。

### 3. 微信内置浏览器 / 手机

把整个文件夹上传到任意静态托管（GitHub Pages、Vercel、对象存储……）后用手机访问即可。
页面已做移动端适配，触控区域、字号、弹幕行数都会自动调整。

## 三、想改内容？只改 script.js 顶部的 CONFIG

`script.js` 第 1–200 行是 `CONFIG` 对象，每一项都有中文注释：

| 想改什么 | 改哪里 |
| --- | --- |
| 寿星姓名、年龄、称呼 | `CONFIG.name` / `CONFIG.age` / `CONFIG.en` |
| 出生日期（计时器基准） | `CONFIG.birthday`，格式 `2004-12-12T00:00:00`（生日 12 月 12 日） |
| 首屏打字机寄语 | `CONFIG.heroNote` |
| 信件正文 | `CONFIG.letter.paragraphs`（数组，每项一段，`\n` 可换行） |
| 信件落款 | `CONFIG.letter.signature` |
| 歌单 | `CONFIG.playlist`（title / artist / src / note） |
| 8 张拍立得 | `CONFIG.gallery`（date / title / caption / photo / pos / quote / reply） |
| 幸运签 / 愿望券 | `CONFIG.slips` |
| 三道默契问答 | `CONFIG.quiz`（题目、4 个选项、每种选择的反馈） |
| 解锁后的隐藏祝福 | `CONFIG.quizReward` |
| 弹幕颜色 | `CONFIG.danmakuColors` |
| 默认弹幕内容 | `CONFIG.danmaku` |

改完保存、刷新页面即可，无需编译。

## 四、替换歌曲（重点：不要放《祝你生日快乐》）

把 mp3 按下面的文件名放进 `assets/music/`，页面会自动读取：

| 曲目 | 文件名 | 说明 |
| --- | --- | --- |
| 曲目 1 | `22.mp3` | 默认主打：陶喆《22》 |
| 曲目 2 | `forest-ambient.mp3` | 森系治愈纯音乐 |
| 曲目 3 | `afternoon.mp3` | 22 岁午后浪漫单曲 |
| 曲目 4 | `custom.mp3` | 自定义专属曲目 |

想加更多歌：在 `CONFIG.playlist` 里追加一项，并给出新的 `src` 路径即可；
想复用同一个文件也可以，把 `src` 指向同一个路径就行。

**文件缺失 / 加载失败时的表现**：不会报错，也不会卡住。播放器会自动切换成
用 Web Audio 实时合成的温柔和弦 + 五声音阶琶音氛围音（完全原创、不含任何
“祝你生日快乐”旋律），并在播放器副标题上显示「氛围音 · 未找到 22.mp3」。
把文件放进去后刷新，就会自动切回原曲。

> 提示：为了兼容性，建议使用 mp3（AAC/MP4 亦可）。文件较大时用 128–192 kbps 即可。

## 五、替换照片

1. 现在 `assets/images/` 里放的是 `image1.jpg` … `image8.jpg`，顺序对应 `CONFIG.gallery` 的 8 张卡片；
2. 换成别的照片：直接覆盖同名文件，或改 `CONFIG.gallery[i].photo` 的路径；
3. 可选字段：`pos` 控制方框裁切焦点（竖图写 `"50% 30%"` 把脸留在框里）；
   `quote` 在灯箱里显示为一句引文，`reply` 显示为「写给你的回复」；
4. 图片不存在时会退回内置的绿色系 SVG 插画（叶片 / 日光 / 山丘 / 月亮 / 新芽 / 星），
   带颗粒质感，不会开天窗。照片只在滚动到附近时才加载，首屏不会因为大图变慢。

## 六、交互清单

- **火漆信封开场**：3D 信封 + 火漆印章，点击后翻盖、抽信纸、彩带绽放，进入主页并自动播放音乐。
- **首屏**：打字机寄语、实时计时器（出生至今 天/时/分/秒）、距离下一个纪念日的提示。
- **手写信**：逐段打字机朗读、一键显示全文、盖章互动（落下印记 + 微光粒子），打开时音乐自动降低音量，关闭恢复。印章只保留在当前这次阅读里，重新打开或刷新页面都会回到「收下这份心意 · 盖章」的未盖章状态。
- **生日蛋糕**：三层绿色奶油蛋糕、三根蜡烛；点击蜡烛 / 「吹灭蜡烛」/ 麦克风吹气（无权限自动降级）都能吹灭，之后升起青烟、放烟花，并抽取一张幸运签。
- **拍立得画廊**：8 张真实照片，点击进入灯箱，支持左右切换、ESC 关闭；第 7、8 张在灯箱里会额外显示朋友圈引用的那句台词和一段「写给你的回复」。
- **默契问答**：3 道题，选完每道都有专属反馈，全部答完解锁隐藏祝福卡。
- **祝福弹幕墙**：默认弹幕循环飘过（可开关 / 调透明度），留言表单可选颜色、发送即飞过并存入 localStorage。
- **烟花**：点「放一场生日烟花」，或点击页面空白处，在 Canvas 上放一朵带重力与拖尾的烟花。
- **双主题**：右上角开关在「森系暮光 / 抹茶奶绿」之间切换，选择会被记住。

## 七、兼容性与注意事项

- 目标浏览器：Chrome / Edge / Safari / 微信内置浏览器（iOS 14+、Android 8+）。
- 字体与彩带库走 CDN（Google Fonts、jsDelivr），**断网时会自动退回系统字体与内置粒子**，不影响任何交互。
- 已适配 `prefers-reduced-motion`：系统开启“减少动态效果”时，打字机与位移动画会自动简化。
- 弹幕留言保存在浏览器 `localStorage`（键名 `ltq22:wishes`），换设备/清缓存会丢失，属正常现象。
- 页面不含任何统计脚本、不上传任何数据，全部逻辑在本地运行。
