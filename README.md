# 22 岁生日快乐 🎂🌿

一个生日纪念网站：绿色系、双主题、火漆信封开场、手写信、吹蜡烛许愿、拍立得画廊、默契问答、祝福弹幕与烟花。

---

## 一、目录结构

```
happybirthday/
├─ index.html            页面结构（语义化标签 + 各弹窗容器）
├─ style.css             绿色双主题变量、3D 信封、毛玻璃、动画与响应式
├─ script.js             全部逻辑；所有可改内容集中在文件顶部的 CONFIG
├─ assets/
│  ├─ music/             自选歌曲（可选，缺失时自动降级为氛围音）
│  │  ├─ 22.mp3
│  │  ├─ forest-ambient.mp3
│  │  ├─ afternoon.mp3
│  │  └─ custom.mp3
│  └─ images/            真实照片（可选，缺失时自动使用内置绿色插画）
│     ├─ photo1.jpg … photo6.jpg
└─ README.md
```
