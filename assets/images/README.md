# assets/images — 真实照片放这里

把照片命名为 `photo1.jpg` … `photo6.jpg` 放进本文件夹即可，
页面启动时会自动探测并把拍立得占位插画替换成真实照片，**不需要改代码**。

| 文件名 | 对应卡片 | 建议内容 |
| --- | --- | --- |
| `photo1.jpg` | 2023 · 春 · 第一片绿 | 初识 / 春天 |
| `photo2.jpg` | 2023 · 夏 · 午后三点 | 夏天 / 咖啡 / 午后 |
| `photo3.jpg` | 2024 · 秋 · 一起走过的路 | 一起出门的那天 |
| `photo4.jpg` | 2024 · 冬 · 雪的来信 | 冬天 / 雪 / 热汤面 |
| `photo5.jpg` | 2025 · 春 · 新长出来的 | 新的开始 / 植物 |
| `photo6.jpg` | 2026 · 今天 · 22 岁的第一天 | 最近的合照 |

- 建议竖版 3:4 或 4:5，长边 1200–2000px；文件别太大（单张 < 1MB 体验最佳）。
- 想换文件名或用 png：改 `script.js` 里 `CONFIG.gallery[i].photo` 的路径。
- 没有照片时，页面会用内置的绿色系 SVG 插画占位（叶片 / 日光 / 山丘 / 月亮 / 新芽 / 星），
  带颗粒与暗角质感，灯箱放大也不空。
