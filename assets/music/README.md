# assets/music — 自选歌曲放这里

把 mp3 按下表的文件名放进本文件夹，页面会自动读取；缺失时自动降级为
Web Audio 合成的温柔和弦氛围音（不含《祝你生日快乐》旋律），不会报错。

| 文件名 | 对应曲目 | 说明 |
| --- | --- | --- |
| `22.mp3` | 曲目 1 · 陶喆《22》 | 默认主打，开场后自动播放 |
| `forest-ambient.mp3` | 曲目 2 · 森系治愈纯音乐 | 适合吹蜡烛时循环 |
| `afternoon.mp3` | 曲目 3 · 22 岁午后浪漫单曲 | — |
| `custom.mp3` | 曲目 4 · 自定义专属曲目 | 换成你们的歌 |

- 想用别的文件名：改 `script.js` 顶部 `CONFIG.playlist[i].src`。
- 想加歌：在 `CONFIG.playlist` 追加一项（title / artist / src / note）。
- 建议 mp3，128–192 kbps；文件名尽量用英文，避免个别服务器路径编码问题。
- 请确保使用的音乐拥有相应版权 / 授权。

> 注意：本项目刻意不使用《祝你生日快乐》的旋律与音效，请勿放入该曲目。
